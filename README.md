# Keyboard Input Simulation

把文字用「**模拟按键**」的方式敲进当前焦点窗口，专治**禁止粘贴**的输入框。

## 原理

调用 Windows 的 `SendInput`，以 `KEYEVENTF_UNICODE` 逐字发送字符码点。目标程序收到的是真实按键消息，而不是剪贴板粘贴，所以即使输入框屏蔽了 Ctrl+V，也能正常输入文字。

## 用法

1. 双击 `模拟键盘输入_ai.pyw`（`.pyw` 不弹黑窗）
2. 把要输入的文字粘进上方输入框
3. 点「开始输入」或按 **F9**
4. 在倒计时内把光标点进目标输入框
5. 中途要停就按 **F10**

勾选「去掉回车」时，多行文字会压成一行再输入，免得回车提前把消息发出去。

## 参数

| 项 | 默认 | 说明 |
|---|---|---|
| 倒计时 | 5 秒 | 留时间切窗口，最长 60 秒 |
| 逐字间隔 | 10 ms | 虚拟机 / 远程桌面吃太快会丢字，建议调到 30 ms |

开始输入前会先松开左右 Shift / Ctrl / Alt / Win，避免修饰键卡住把输出搞乱。
